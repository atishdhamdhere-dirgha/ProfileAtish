## 🚀 How to Run Locally

### Option 1: Open Directly in Browser
You can directly open `index.html` in Chrome, Edge, Safari, or Firefox by double-clicking it.

### Option 2: Run via Local Python Server
```bash
cd "C:\Users\DELL\.gemini\antigravity\scratch\atish-dhamdhere-portfolio"
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Option 3: Run via Node / npx
```bash
npx serve .
```

## 🌐 Free 1-Click Hosting / Deployment

This is a zero-dependency static website and can be deployed instantly for free on any platform:

### 1. GitHub Pages
1. Push this folder to a GitHub repository (e.g. `atish-dhamdhere.github.io`).
2. Go to **Settings > Pages > Branch: `main` / `root` > Save**.
3. Your portfolio is live with SSL at `https://<username>.github.io`.

### 2. Netlify Drop
- Simply drag-and-drop the entire `atish-dhamdhere-portfolio` folder into [Netlify Drop](https://app.netlify.com/drop).
- Done in 10 seconds!

### 3. Vercel
```bash
npx vercel
```
